# Visus Patente

App Android per tablet con i test visivi per il conseguimento e il rinnovo della patente: acuità visiva (anche per analfabeti), astigmatismo, visione dei colori, campo visivo, sensibilità al contrasto, visione crepuscolare con e senza abbagliamento.

## Aggiornamenti

L'app controlla da sola l'ultimo rilascio di questo progetto. Per pubblicare una nuova versione: alza i numeri nel file VERSION, ricompila con build.sh e crea un rilascio con etichetta vX.Y allegando VisusPatente.apk.
